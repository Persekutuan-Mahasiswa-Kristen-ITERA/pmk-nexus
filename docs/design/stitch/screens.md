# Stitch design snapshot: PMK-NEXUS Dashboard Redesign

Source: Stitch project `projects/15744631264658346759` ("PMK-NEXUS Dashboard Redesign"). Read-only snapshot taken 2026-11-05.
Only the HTML of each screen was saved (in `html/`). Screenshots were skipped on purpose. Screen `6286551280247083640` ("image.png", an uploaded reference image) has no HTML and was skipped.

All screens are single-file Tailwind CDN pages (`cdn.tailwindcss.com?plugins=forms,container-queries`), mobile-first, Indonesian UI text, `lang="id"`. Icons: Google Material Symbols Outlined. Fonts: Playfair Display (serif display) and Plus Jakarta Sans (body, labels, numbers).

NOTE on screen 7: the screen titled "Finance (390px, no screenshot)" actually contains the **Dashboard** HTML (same as screen 1, byte-for-byte as far as visually compared; the file was created by copying file 01). It is not a Finance screen.
